🛣️ How to use this repo

01
New to Java? Module 00 + the Memory Visualizer until stack-vs-heap feels obvious. Experienced? Skim it anyway.
02
Daily loop: open the Command Center → start the chrono → do the next unticked task on the board → clear the review queue → one Trap Trainer round.
03
Weekly: rewrite The Wall from memory on Sunday, feed the gaps to Anki (deck included: flashcards/).
04
From week 6: full Exam Simulator sittings. Three in a row ≥ 80% opens the booking gate. Then the Playbook, then the badge. 🏆
