Allocate objects, drop some references, then run a Minor GC: dead objects vanish, live ones move to a Survivor space and age (number on the chip). At age 3 they're promoted to the Old Generation. This is exactly why "most objects die young" makes Java fast.

  

  
🎯 Exam facts: GC frees only UNREACHABLE objects · System.gc() is a request, not a command · setting a reference to null or re-pointing it can make objects eligible · islands of isolation are collected too · StackOverflowError is a stack problem, OutOfMemoryError a heap problem.
